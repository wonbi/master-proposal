📸 상품 사진·스펙 자동 업데이트 도구

상품 관리자에 등록해둔 원본 링크(masterc.kr 등)에서 사진·스펙을 다시 긁어와 채워줍니다.

0. 준비물

  1. 상품 관리자에서 상품마다 "원본 링크" 칸에 masterc.kr 등 상세페이지 주소를 넣고 저장해둡니다.
  2. 상품 관리자 상단의 [📸 북마클릿 토큰 복사] 버튼을 눌러 로그인 토큰을 복사해둡니다. (1시간 동안 유효 — 만료되면 다시 복사)

1. 즐겨찾기에 한 번만 등록

아래 초록 버튼을 즐겨찾기 바로 끌어다 놓으세요. (Ctrl+Shift+B 로 즐겨찾기 바 켜기)

📸 사진·스펙 업데이트

끌어다 놓기가 안 되면 즐겨찾기를 새로 추가하고 URL 칸에 아래 주소를 붙여넣으세요.

2. 쓰는 법

  1. masterc.kr에 로그인된 탭을 엽니다. (사진은 로그인해야 보이므로 반드시 그 사이트 위에서 실행해야 합니다)
  2. 즐겨찾기의 📸 사진·스펙 업데이트를 누르면 오른쪽 아래에 패널이 뜹니다.
  3. 처음 실행 시 토큰 붙여넣기 창이 뜨면, 0번에서 복사해둔 토큰을 붙여넣습니다. (이 탭에서만 기억되고, 창을 닫으면 사라집니다 — 다음에 또 붙여넣으면 됩니다)
  4. 업데이트할 상품을 고릅니다.
    • 누락만 — 사진 또는 스펙이 비어 있는 상품
    • 전체 — 링크가 있는 모든 상품 다시 긁기
  5. 선택 N건 업데이트를 누르면 순서대로 긁어서 바로 저장됩니다.
  6. 공개 사이트나 관리자 화면을 새로고침하면 반영됩니다.
⚠️ 사진·스펙을 뽑아내는 규칙(어떤 태그에서 가져올지)은 masterc.kr 실제 페이지 구조를 보고 튜닝이 필요할 수 있어요. assets/photo-updater.js 맨 위 EXTRACT 규칙 부분만 고치면 됩니다. 처음 몇 건 돌려보고 결과가 안 맞으면 알려주세요 — 선택자를 맞춰드릴게요.

3. 어디에 저장되나

긁은 사진 주소·스펙 텍스트는 그 상품의 Supabase products 행에 바로 저장됩니다. 상품 관리자에서 직접 고쳐도 되고, 특정 상품 사진을 지우고 싶으면 관리자에서 사진 칸을 비우면 "사진 준비중"으로 표시됩니다.
