# 상품 제안서 (B2B 공동구매 마켓)

주식회사 마스터 외부유통팀이 공동구매 마켓·B2B 도매 거래처에 보내는 **상품 제안서** 웹사이트입니다.

## 구조 한눈에

```
거래처(B2B)  ──본다──▶  🌐 공개 사이트 (GitHub Pages)
                              ▲
                              │ 자동으로 읽어옴
                              │
나(관리자)  ──수정──▶     📝 구글 시트 (상품·가격·택배비)
```

- **공개 사이트**: 링크만 있으면 로그인 없이 열람. 예: `https://wonbi.github.io/master-proposal/`
- **구글 시트**: 내가 상품을 수정하는 곳. 시트를 고치면 공개 사이트에 자동 반영됨.
- 시트를 연결하기 전에도 기본 상품 24종이 그대로 표시됩니다.

👉 **설치·사용법은 [SETUP.md](SETUP.md) 를 보세요.** (한글, 단계별)

## 파일 구성

| 경로 | 설명 |
|------|------|
| `index.html` | 공개 사이트 페이지 |
| `assets/style.css` | 디자인 스타일 (원본 핸드오프 스펙 그대로) |
| `assets/app.js` | 시트/기본데이터 읽어와 화면 그리는 로직 |
| `config.js` | **여기만 고침** — 구글 시트 연결 + 회사/담당자 정보 |
| `data/products.json` | 기본 상품 24종 (시트 미연결 시 사용) |
| `상품시트-템플릿.csv` | 구글 시트에 가져올 상품 템플릿 |
| `전체상품-시트.csv` | 취급 전체 상품(약 630종)을 담은 CSV — 관리자의 [CSV 대량 가져오기]로 "전체상품" 버전을 만들 때 사용 (`ADMIN-SETUP.md` 참고) |
| `all-products.html` | 로그인·가격숨김 없이 전체 상품(약 630종)을 **창고별로** 모아 보여주는 별도 페이지. `data/all-products.json` 스냅샷 기반, 상품명 검색 지원 |
| `data/all-products.json` | `all-products.html` 이 읽는 전체 상품 데이터(마스터 유통시트 스냅샷) |
| `images/products/` | 상품 사진 24장 |
| `.github/workflows/deploy-pages.yml` | 푸시 시 자동 배포 |
| `SETUP.md` | 사용 설명서 |

## 기술 메모

- 프레임워크 없는 정적 사이트(HTML/CSS/바닐라 JS) — 빌드 과정 없이 GitHub Pages로 바로 배포됩니다.
- 상품 데이터는 구글 시트의 공개 CSV(gviz) 엔드포인트를 브라우저에서 직접 읽습니다.
  시트가 없거나 오류가 나면 `data/products.json` 으로 자동 폴백하므로 사이트가 깨지지 않습니다.
- 디자인 토큰·컴포넌트는 원본 디자인 핸드오프 번들 스펙을 그대로 재현했습니다.
